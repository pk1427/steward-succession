# Seven libraries catalogue stewardship agreement

The seven library committees jointly control the root authority and approve a replacement publisher by recorded majority resolution. The treasury node wallet pays the postage batch; it is operationally separate from the steward signing identity, although a shared Bee node means batch custody is not individually separated.

**Current publisher / named successor:** `0x2B8bff28f868FB662B48d8C3CfF5567CC84c1130` (incoming steward signing identity). This public identity is separate from the council root authority and the outgoing publisher.

**Trigger:** succession begins if the current steward has not acknowledged two committee contact attempts made at least 14 days apart, or resigns in writing. The council signs the root-pointer rotation and releases the successor key procedure. The successor then publishes a catalogue feed; readers keep using the stable root pointer.

Storage is a renewable subscription. The treasury reviews and extends the existing batch every quarter; a new batch is not presented as a substitute for renewing the archive.
